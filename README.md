# PE-Harbour-Network-Infrastructure
Enterprise network design and implementation for Port Elizabeth Harbour featuring VLANs, OSPF, NAT, VPN, ACLs, VoIP, and network security using Cisco Packet Tracer.

Port Elizabeth Harbour Network Infrastructure

Project Overview
This project was developed as part of a third-year networking qualification and focuses on the design and implementation of a secure, scalable, and fault-tolerant network infrastructure for Port Elizabeth Harbour.

Technologies Used
Cisco Packet Tracer
VLANs
Inter-VLAN Routing
OSPF
NAT
VPN
ACLs
VoIP
DHCP
DNS
Wireless Networking

Key Features

Departmental VLAN Segmentation
Dynamic Routing using OSPF
Network Address Translation (NAT)
Site-to-Site VPN Connectivity
Access Control Lists (ACLs)
VoIP Communication System
Centralized Server Infrastructure
Network Security Controls
